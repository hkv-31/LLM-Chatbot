MACHINE LEARNING REFERENCE

Machine learning is a branch of artificial intelligence in which models
learn patterns from data and use those learned patterns to make predictions
or decisions.

Supervised learning uses labelled training data. The model learns a mapping
between input features and known target values. Classification predicts
discrete categories, while regression predicts continuous numerical values.

Unsupervised learning works with data without target labels. It can be used
to discover structure or patterns in the data. Clustering groups similar
observations, while dimensionality reduction represents data using fewer
dimensions.

A machine learning workflow commonly includes data collection, preprocessing,
feature engineering, dataset splitting, model training, validation,
evaluation, and deployment.

Common evaluation metrics include accuracy, precision, recall, F1 score,
mean squared error, and mean absolute error. The appropriate metric depends
on the problem and the consequences of different types of errors.

DEEP LEARNING REFERENCE

Deep learning uses neural networks with multiple layers to learn
representations from data.

Artificial neural networks consist of interconnected computational units.
Each unit typically applies a weighted transformation followed by an
activation function.

Convolutional neural networks are commonly used for image and spatial data.
Recurrent architectures were historically used for sequential data.
Transformer architectures use attention mechanisms and are widely used in
modern language models and other sequence-processing applications.

LARGE LANGUAGE MODEL REFERENCE

A large language model processes sequences of tokens and predicts or
generates text based on learned statistical patterns.

A typical LLM application contains system instructions, user input,
optional context, model inference, and response processing.

The system prompt establishes persistent instructions or context.
The user message contains the current request. Additional retrieved
documents or conversation history may provide context for the model.

RAG REFERENCE

Retrieval-augmented generation combines information retrieval with
language generation.

A typical RAG pipeline contains document ingestion, text chunking,
embedding generation, vector storage, retrieval, context construction,
and language-model generation.

During a query, relevant documents or passages are retrieved and supplied
to the language model as additional context.

RAG can help an application answer questions using external or
domain-specific information without requiring the model to have memorized
that information during training.

API REFERENCE

An API defines how software components communicate.

HTTP APIs commonly expose endpoints that receive requests and return
structured responses. JSON is a common representation format.

A typical API request can contain a method, URL, headers, authentication
information, query parameters, and a request body.

A typical API response can contain a status code, headers, and response
data.

CLOUD COMPUTING REFERENCE

Cloud computing provides computing resources such as compute, storage,
databases, networking, monitoring, and managed services through remote
infrastructure.

Common cloud deployment concepts include virtual machines, containers,
serverless functions, object storage, managed databases, virtual networks,
and application programming interfaces.

SOFTWARE ENGINEERING REFERENCE

Software engineering involves designing, implementing, testing, deploying,
maintaining, and improving software systems.

Important concepts include modularity, abstraction, version control,
testing, documentation, error handling, observability, maintainability,
security, and performance optimization.

DATABASE REFERENCE

A database stores and organizes information so that applications can
efficiently create, retrieve, update, and delete data.

Relational databases organize information using tables and relationships
and commonly use SQL. NoSQL databases can use alternative data models such
as documents, key-value pairs, wide columns, or graphs.

COMPUTER VISION REFERENCE

Computer vision focuses on extracting information from images or video.

Common tasks include image classification, object detection,
image segmentation, optical character recognition, and tracking.

NATURAL LANGUAGE PROCESSING REFERENCE

Natural language processing focuses on computational processing of human
language.

Common tasks include classification, information extraction,
summarization, translation, question answering, text generation,
and sentiment analysis.

PROMPT CACHING REFERENCE

Prompt caching can reduce repeated computation when requests share an
identical prefix.

A good prompt-caching design places stable system instructions,
reference information, and reusable context at the beginning of the
prompt. Dynamic user-specific information should appear after the stable
prefix.

The purpose of caching is to reuse computation for repeated prompt
content. Caching does not change the intended instructions or require
changing the model's response-generation behavior.

PERFORMANCE REFERENCE

LLM application performance can be evaluated using metrics such as
input token count, output token count, total token count, latency,
throughput, cache hit rate, and estimated cost.

Reducing unnecessary input tokens can reduce processing requirements.
Caching repeated prompt prefixes can reduce the effective cost of repeated
input content when cache hits occur.

SECURITY REFERENCE

LLM applications should consider authentication, authorization,
input validation, sensitive-data handling, prompt injection,
output validation, rate limiting, logging, and secure secret management.

API keys should not be hardcoded in source code. Environment variables or
secure secret-management systems should be used instead.

Always prioritize correctness, clarity, relevance, and technical accuracy.
